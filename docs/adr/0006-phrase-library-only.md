# 0006: The protected user sees only phrase-library text, never Muse Spark's words

Every command and counter-move shown to the protected user comes from the fixed, reviewed phrase library, chosen by stage
and language. Muse Spark returns a counter-move phrase ID, and official numbers come from `official_contact`. Spark writes
free text only for the family alert summary (200 characters max, plus up to two masked quotes).

**Why:** the transcript is untrusted. If Spark wrote the on-screen text, a scammer's line could steer what grandma reads at
the worst moment. Fixed text also keeps the command identical every time, which an elderly user needs, and makes the
evaluation repeatable. The cost is less tailored coaching, so the library must cover every stage in every language.
