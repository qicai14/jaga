# Local tickets (until 26 Oct)

Before the GitHub repo exists, the spec (`spec.md`, from `/to-spec`) and tickets live here, one Markdown file each
(`NNN-slug.md`), written by `/to-tickets`.
Each ticket lists its lane, its acceptance criteria and the tickets that **block** it.

On 26 Oct the lead moves them to GitHub Issues (`gh issue create` per file) and this folder is deleted.
